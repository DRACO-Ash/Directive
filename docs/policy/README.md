# Policy source documents

The two documents this application is built against, stored verbatim so the conformance
table in `../DEPLOYMENT.md` can be audited rather than taken on trust. Both are
**COMMERCIAL IN CONFIDENCE**, which is the classification of this repository.

● `AUD-001-audit-controls.md`: Audit and Monitoring Policy addendum, application audit
  controls. Governs what the audit log captures, its integrity, retention and review.
● `AMD-001-security-policy-amendment.md`: Information Security Policy amendment. Governs
  change control, accreditation, and the Secure Development Lifecycle in section 10.6.

Both carry an unsigned approval row: Adam Field's date is blank on each. They are treated
as binding on this build, and that gap is recorded rather than assumed closed.

Provenance: supplied by Ash Higgins (ISM and DPL) in the build session of 20 August 2026,
transcribed verbatim from the source documents. If the originals are amended, replace
these files and re-check every row of the conformance table against them: several rows in
that table exist only because a clause here says something specific.
